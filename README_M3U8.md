# Buscador de Listas M3U8 (IPTV Searcher)

Uma ferramenta simples em Python para baixar listas públicas de IPTV (como as do projeto `iptv-org`), pesquisar canais por nome ou categoria, visualizar as URLs e exportar os resultados filtrados para um novo arquivo `.m3u`.

## Como usar

Execute o script com o Python 3:

```bash
python3 m3u8_searcher.py
```

### Funcionalidades:
1. **Fontes pré-configuradas:** Escolha entre listas gerais, do Brasil, de Portugal, Filmes ou Esportes.
2. **URL Personalizada:** Insira qualquer link direto para uma lista `.m3u` ou `.m3u8`.
3. **Busca interativa:** Pesquise por termos como "ESPN", "Globo", "SportTV", etc.
4. **Exportação:** Salve os canais filtrados em um novo arquivo `.m3u` pronto para uso em players como VLC, Kodi ou IPTV Smarters.
